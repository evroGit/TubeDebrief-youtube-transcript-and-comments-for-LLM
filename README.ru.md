# Copy YouTube Comments for LLM

*[Read in English](README.md)*

Chrome extension: собирает под текущим YouTube-видео комментарии и/или транскрипт (субтитры), формирует один большой prompt и копирует его в буфер обмена — вставить в ChatGPT/Claude/Gemini/Perplexity пользователь должен сам (либо это делает experimental auto-paste).

Никаких батчей, никакой интеграции с LLM API, никакого обязательного side panel — максимум простоты.

## Как это работает

1. Открываете видео на `youtube.com/watch...`.
2. Выбираете в popup, что собирать (`Что собирать`): **комментарии**, **транскрипт** или **оба** источника. По умолчанию — комментарии.
3. Нажимаете **"Copy"** — либо кнопку прямо на странице (рядом с лайком/дизлайком), либо в popup расширения.
4. Если нужен транскрипт: расширение раскрывает описание, открывает панель транскрипта YouTube и вычитывает её сегменты. Сегменты группируются в абзацы — новый абзац с таймкодом `[мм:сс]` начинается не чаще раза в `transcriptTimestampInterval` секунд, чтобы таймкоды не съели весь объём prompt.
5. Если нужны комментарии: расширение переключает сортировку на "Top comments", затем скроллит страницу, подгружая комментарии (и, если включено, разворачивает replies), пока не наберёт нужное количество / объём символов. Локальный фильтр отсеивает пустые, emoji-only, ссылки-без-текста и дубликаты, оставляет комментарии не короче `minChars`/`minWords`.
6. Формируется один текст: инструкция для LLM (свой шаблон на каждый режим) + транскрипт и/или пронумерованный список комментариев вида `[1] (👍 245, 87 chars) текст...`, и сохраняется (`chrome.storage.local`) как "последний скопированный текст". Когда в prompt попадают оба источника, они разделяются заголовками `=== ТРАНСКРИПТ ===` и `=== КОММЕНТАРИИ (N) ===`; при одном источнике заголовки не добавляются.
7. Текст копируется в буфер обмена.
8. Дальше **отдельно**, сколько угодно раз, нажимаете любую из кнопок **"Open ChatGPT" / "Open Claude" / "Open Gemini" / "Open Perplexity" / "Open Custom"** — каждая открывает новую вкладку с этим сайтом и пытается автоматически вставить туда сохранённый текст. Сбор при этом не повторяется — можно открыть хоть все пять LLM подряд из одного Copy.
9. Если авто-вставка не сработала — вставляете вручную (Ctrl+V), текст уже в буфере обмена.

## Источник данных: DOM scraping

Выбран DOM scraping страницы YouTube (не YouTube Data API), потому что:

- не нужен API key, OAuth или квоты;
- работает сразу после установки, без единой настройки;
- MVP не требует 100% полноты комментариев — только доступные без лишних действий пользователя.

Скролл прогружает ленту комментариев порциями; если включена опция **Include replies**, расширение дополнительно кликает по кнопкам "Показать ответы" перед сбором текста. Если опция выключена, ответы просто не разворачиваются и не попадают в выборку — дополнительная фильтрация не нужна.

Транскрипт читается из той же панели транскрипта, которую YouTube показывает пользователю по кнопке "Показать транскрипт". Кнопка и панель ищутся по структуре DOM, а не по тексту, — иначе понадобилась бы таблица переводов на все языки интерфейса YouTube. Транскрипт есть только у видео с субтитрами (в том числе автоматическими); если субтитров нет, панель не открывается, и режим "транскрипт" честно сообщает, что собирать нечего.

## Настройки (chrome.storage.local)

| Настройка | Где менять | Описание |
|---|---|---|
| `contentSource` | popup / options | что собирать: `comments` / `transcript` / `both`. По умолчанию `comments` — поведение до появления транскрипта |
| `minChars` | popup / options | минимальная длина комментария в символах |
| `minWords` | options | минимальное число слов |
| `maxComments` | popup / options | максимум отобранных комментариев |
| `maxTotalChars` | options | максимальный суммарный объём текста комментариев |
| `includeReplies` | popup / options | собирать ли ответы на комментарии |
| `customLLMUrl` | popup / options | URL для кнопки "Open Custom" |
| `uiLanguage` | options | язык интерфейса (popup, options, кнопки/статусы на странице YouTube) и язык prompt: `ru` / `en` / `de` |
| `transcriptTimestampInterval` | options | новый абзац транскрипта с таймкодом `[мм:сс]` начинается не чаще раза в N секунд. `0` — без таймкодов вообще (весь транскрипт одним абзацем) |
| `maxTranscriptChars` | options | лимит символов на транскрипт. При превышении транскрипт обрезается по границе абзаца (а если весь транскрипт — один абзац, то по границе слова) с явной пометкой в тексте |
| `promptTemplate` | options | инструкция для LLM в режиме **комментариев** (плейсхолдеры `{{videoTitle}}`, `{{videoUrl}}`, `{{count}}`) |
| `transcriptPromptTemplate` | options | то же для режима **транскрипта**: просит summary, разбор по блокам с таймкодами и предупреждает LLM, что текст может быть распознан автоматически |
| `combinedPromptTemplate` | options | то же для режима **оба**: дополнительно просит сопоставить комментарии с содержанием видео |
| `lastPromptText` | внутреннее | последний собранный текст, используется всеми кнопками Open |
| `lastPromptVideoId` | внутреннее | id видео, для которого собран последний текст; по нему кнопки Open решают, активны они или нет |

Все три шаблона prompt редактируются в options, но одновременно виден только шаблон выбранного режима — остальные сохраняются как есть. При смене языка каждый шаблон автоматически переключается на дефолтный шаблон **этого** языка, только если он ещё не был кастомизирован; кастомный текст не трогается.

В режиме **оба** отсутствие транскрипта не считается ошибкой: у видео без субтитров всё равно есть комментарии, поэтому расширение собирает их, использует шаблон для комментариев и дописывает в статус "транскрипт недоступен". Ошибка — только если не собрано вообще ничего.

## Архитектура

```
manifest.json
background/service-worker.js   — открывает вкладку с LLM, дожидается её загрузки, шлёт туда текст для авто-вставки; badge с прогрессом
content/youtube.js             — инжектит кнопки Copy + Open×5, оркестрирует collect → filter → build → copy
content/autopaste.js           — experimental: вставляет текст в поле ввода ChatGPT/Claude/Gemini/Perplexity
popup/popup.html, popup.js     — настройки + кнопка Copy + кнопки Open для каждого LLM
options/options.html, options.js — полный набор настроек
core/commentCollector.js       — скролл страницы, раскрытие replies, сбор сырых текстов
core/transcriptCollector.js    — открывает панель транскрипта YouTube и вычитывает её сегменты (текст + таймкод)
core/filter.js                 — локальный эвристический фильтр + дедупликация + лимиты
core/promptBuilder.js          — сборка финального текста для LLM
core/i18n.js                   — словарь UI-строк и prompt-шаблонов на ru/en/de, функция t(lang, key)
core/clipboard.js              — запись в буфер обмена через offscreen-документ (fallback: navigator.clipboard / execCommand)
offscreen/offscreen.html, offscreen.js — offscreen-документ: пишет в буфер обмена без требования фокуса вкладки / user gesture (см. manifest permission "clipboardWrite")
core/targets.js                — предустановленные URL LLM-чатов
core/storage.js                — обёртка над chrome.storage.local с дефолтами + хранение последнего текста
core/openTarget.js             — общий "открыть LLM с последним текстом", используется и popup, и content script
```

Модули `core/*` подключены как обычные classic scripts (без сборки/бандлера — соответствует принципу максимальной простоты) и делят общую глобальную область видимости в контенте, куда они внедряются (content script и popup/options).

## Установка как unpacked extension

1. Откройте `chrome://extensions`.
2. Включите **Developer mode** (переключатель в правом верхнем углу).
3. Нажмите **Load unpacked**.
4. Выберите папку с этим расширением (там, где лежит `manifest.json`).
5. Откройте любое видео на YouTube — рядом с кнопками лайка появятся **"Copy"** и кнопки **"Open ..."**, либо откройте popup расширения через иконку в панели инструментов.

**После любого изменения `manifest.json`** (например, добавления нового домена в `host_permissions`) нужно нажать **Reload** для расширения на `chrome://extensions` — иначе новые домены/content scripts не подхватятся.

## Ограничения MVP

- DOM-селекторы YouTube могут измениться — если кнопка "Copy" перестанет собирать комментарии, вероятно, изменилась структура `ytd-comments` и селекторы в `core/commentCollector.js` нужно обновить. То же для транскрипта: селекторы панели (`ytd-engagement-panel-section-list-renderer[target-id="engagement-panel-searchable-transcript"]`) и сегментов (`ytd-transcript-segment-renderer`) живут в `core/transcriptCollector.js`.
- Сбор не гарантирует 100% всех комментариев под видео — только те, что удалось прогрузить скроллом за разумное число итераций.
- Язык дорожки субтитров не выбирается: берётся та, которую YouTube открывает в панели по умолчанию. Если у видео несколько дорожек и нужна конкретная, переключите её в панели транскрипта вручную и нажмите Copy повторно.
- Автоматические субтитры приходят без пунктуации и заглавных букв, с ошибками в словах и именах — качество транскрипта задаёт качество summary. Шаблоны prompt для транскрипта прямо предупреждают об этом LLM, но восстановить потерянное в распознавании они не могут.
- Транскрипт длинного ролика может не поместиться в один prompt: часовое видео — это порядка 50 000 символов, и при превышении `maxTranscriptChars` текст обрезается с пометкой. Разбиения на части (map-reduce по чанкам) нет — это противоречило бы принципу "одна вставка, без API".
- Автоматическая вставка текста в чат LLM не является core-гарантией — реализована как **experimental bonus** (`content/autopaste.js`) для ChatGPT/Claude/Gemini/Perplexity: после открытия вкладки и её полной загрузки расширение пытается найти поле ввода и вставить туда текст. Если селекторы сайта изменятся и вставка не сработает — это не считается ошибкой пайплайна: текст уже лежит в буфере обмена, и его можно вставить вручную (Ctrl+V). Для Custom URL авто-вставка не выполняется — только копирование и открытие вкладки.
- Язык кнопок на странице YouTube фиксируется в момент их создания (при загрузке/навигации на видео). Если сменить язык в options, пока вкладка YouTube уже открыта, кнопки на странице обновятся только после перезагрузки этой вкладки — popup обновляется сразу при каждом открытии.
